# Differential correctness gate

Status: measured on 2026-11-02. Thresholds were fixed in
[SCT_V2_SPEC.md](SCT_V2_SPEC.md) before these oracle results were inspected.

## Isolation and provenance

The fixtures are synthetic Gamma--Poisson count matrices generated by
`benchmarks/generate_fixture.py` under this repository's BSD-3-Clause license. The seed is
`20261102`; inputs, ordered names, and one persisted all-eligible selection manifest define
all three levels. Level A consumes all candidates through `n_genes=NULL`/`n_cells=NULL`.
Level B's public manifest type accepts only genes that actually enter NB fitting, so the
exporter explicitly removes genes selected by the documented Poisson rule from that same
candidate list. The original manifest hash and this adapter are recorded in provenance;
Level C consumes the persisted manifest directly.

| Fixture | Shape (genes x cells) | Eligible genes | Counts SHA-256 |
|---|---:|---:|---|
| small | 800 x 240 | 778 | `daa4251f89ad449d0508ebef01bca762ea3960830b0160623d809db1131c2337` |
| larger | 3200 x 240 | 3113 | `8ae3c89d6e6fcb7290c3b750dd0544d6b2be52734fb6872a444d89ac17f9710a` |

- Level A: external R 4.5.2 process, `sctransform` 0.4.3, `glmGamPoi` 1.22.0,
  `matrixStats` 1.5.0.
- Level B: installed `Bowen-Man/sctransform-cpu` v0.4.0 at commit
  `b79041796e3f7ca3b33029adde5d7132eedd2430`, called only through its public API.
- Level C: this repository's independent NumPy/SciPy implementation.

No oracle package, R runtime, generated binary, or golden output is packaged or committed.
The exporters write only to the ignored `benchmark-results/` directory. Level A and B are
execution-time black boxes and are not dependencies of the package, build, or CI.

## Final-parameter residual isolation

The residual stage can be tested independently of selection, fitting, and
regularization by injecting Level A's final intercept and theta into the native
residual core. This is a diagnostic benchmark only: the R runtime and exported
arrays remain external and are never package or CI dependencies.

On the larger fixture, the native residual matrix agrees with the R oracle at
double-precision scale:

| Quantity | RMSE | Max abs. |
|---|---:|---:|
| clipped Pearson residual | 2.25e-14 | 3.43e-13 |
| residual mean | 1.96e-14 | 8.17e-14 |
| residual variance | 2.06e-14 | 9.79e-14 |

The complete HVG order is identical. This isolates the existing end-to-end
residual RMSE of 0.014760 to upstream parameter estimation or regularization,
not the residual formula, variance floor, clipping, or ranking implementation.
The diagnostic gate requires RMSE `<= 1e-12`, maximum absolute error
`<= 1e-10`, and an identical complete HVG order.

```bash
python -m benchmarks.diagnose_residuals \
  --fixture benchmark-results/large/fixture.npz \
  --r-oracle benchmark-results/large/r-oracle \
  --output benchmark-results/large/residual-reinjection.json \
  --enforce
```

## Dispersion regularization A/B

The larger fixture was also run with the same counts, manifest, raw estimator,
bandwidth selector, smoother, and thresholds while changing only the dispersion
target and inverse transform. `native` is the alpha default;
`sct_v2` uses `log10(1 + geometric_mean / theta)` and its matching inverse.

| Quantity | `native` | `sct_v2` |
|---|---:|---:|
| regularized log10(theta) RMSE | 0.046279 | 0.032621 |
| regularized log10(theta) Spearman | 0.996418 | 1.000000 |
| regularized intercept RMSE | 0.001132 | 0.003111 |
| clipped residual RMSE | 0.014760 | 0.015872 |
| clipped residual Pearson | 0.999975 | 0.999980 |
| residual variance RMSE | 0.028817 | 0.029812 |
| Top-1000 HVG Jaccard | 0.956947 | 0.951220 |
| Top-2000 HVG Jaccard | 0.986097 | 0.987084 |

The v2 transform materially improves regularized-theta agreement, but it does
not improve every downstream metric in isolation. The current outlier mask is
the union of intercept and dispersion residual outliers, so changing the
dispersion target also changes the genes used to smooth the intercept. This is
evidence to isolate outlier behavior next, not evidence to change the default.
Both modes pass the original alpha gate.

```bash
python -m benchmarks.compare_correctness \
  --fixture benchmark-results/large/fixture.npz \
  --manifest benchmark-results/large/fixture.selection.json \
  --r-oracle benchmark-results/large/r-oracle \
  --reference benchmark-results/large/reference-v0.4.0.npz \
  --dispersion-regularization sct_v2 \
  --output benchmark-results/large/correctness-sct-v2.json \
  --enforce
```

## Parameter-outlier checkpoint

The Level A exporter persists the named `model_pars_outliers` vector exposed by
the public `vst()` result. The correctness report compares this mask by gene
name, so outlier behavior is observable without reading or packaging GPL
implementation code. This checkpoint is diagnostic and has no acceptance gate
yet.

On the larger fixture, Level A marks 150 genes as parameter outliers. The
default `native` rule marks 176 genes, overlaps on 144, and has Jaccard
`0.791209`. With `dispersion_regularization="sct_v2"`, the current global-MAD
rule marks no genes, giving Jaccard `0.0` with Level A.

This localizes the mixed A/B result above: the v2 dispersion transform improves
regularized theta, but the native outlier rule is not invariant to that change
of coordinates. The 2022 paper specifies the v2 model changes but does not
fully specify the historical binned outlier helper. A clean-room compatibility
implementation therefore remains `unknown`; the next safe step is additional
black-box experiments or an independently published algorithmic specification,
not source translation.

## Raw-theta finite/Inf checkpoint

Raw-theta comparisons now report the named finite/Inf mask separately instead
of silently restricting every conclusion to pairs that are finite on both
sides. On the larger fixture, Levels A and B both contain the same 150 infinite
raw-theta genes. The native estimator contains none, so its mask Jaccard with
either oracle is `0.0` even though the finite-pair theta rank gate passes.

As a diagnostic hypothesis, the benchmark computes the method-of-moments
estimate

```text
theta_mm = mean**2 / (variance - mean)
```

when `variance > mean`, and flags a native fit when
`theta_mm / theta_native < 1e-3`. This selects 155 genes, 149 of which are in
the 150-gene Level A Inf set (Jaccard `0.955128`). The high overlap confirms
that a moment-to-fit ratio explains most of the branch difference. It is not
an exact match because the native and oracle estimators are different, and the
diagnostic is not yet a core postprocessing policy.
