# Differential correctness gate

Status: measured on 2026-11-02. Thresholds were fixed in
[SCT_V2_SPEC.md](SCT_V2_SPEC.md) before these oracle results were inspected.

## Isolation and provenance

The fixtures are synthetic Gamma--Poisson count matrices generated by
`benchmarks/generate_fixture.py` under this repository's BSD-3-Clause license. The seed is
`20261102`; inputs, ordered names, and one persisted all-eligible selection manifest define
all three levels. Level A consumes all candidates through `n_genes=NULL`/`n_cells=NULL`.
Level B's public manifest type accepts only genes that actually enter NB fitting, so the
exporter explicitly removes genes selected by the documented Poisson rule from that same
candidate list. The original manifest hash and this adapter are recorded in provenance;
Level C consumes the persisted manifest directly.

The default native generator now follows the v2 cell-first and inverse-density selection
semantics, but correctness gates continue to replay the persisted manifest rather than
compare language-specific random streams. A regression run after this change preserved
all small and large fixture gates, including exact large-fixture HVG Top 1000/2000/3000.
**measured on 2026-11-02**

| Fixture | Shape (genes x cells) | Eligible genes | Counts SHA-256 |
|---|---:|---:|---|
| small | 800 x 240 | 778 | `daa4251f89ad449d0508ebef01bca762ea3960830b0160623d809db1131c2337` |
| larger | 3200 x 240 | 3113 | `8ae3c89d6e6fcb7290c3b750dd0544d6b2be52734fb6872a444d89ac17f9710a` |

- Level A: external R 4.5.2 process, `sctransform` 0.4.3, `glmGamPoi` 1.22.0,
  `matrixStats` 1.5.0.
- Level B: installed `Bowen-Man/sctransform-cpu` v0.4.0 at commit
  `b79041796e3f7ca3b33029adde5d7132eedd2430`, called only through its public API.
- Level C: this repository's independent NumPy/SciPy implementation.

No oracle package, R runtime, generated binary, or golden output is packaged or committed.
The exporters write only to the ignored `benchmark-results/` directory. Level A and B are
execution-time black boxes and are not dependencies of the package, build, or CI.

## Stage-wise diagnostic contract

The same comparison command now emits a versioned `stages` record without changing any
gate or numerical path:

- `input`: fixture shape, counts SHA-256, ordered-cell agreement;
- `selection`: manifest SHA-256 and algorithm, selected sizes, raw-fit gene-set overlap,
  and fit-cell order when the oracle artifact exposes it;
- `raw_fitting`: intercept and log10(theta) metrics, finite/Inf/NaN classification,
  relative theta error, deterministic top-error genes, and native convergence summaries;
- `regularization`: final parameter metrics and the named outlier mask;
- `residual`: matrix, mean, and variance metrics plus genes ranked by row RMSE;
- `hvg`: Top-K overlap, complete gene-set overlap, exact-order status, and complete-rank
  Spearman correlation.

Relative error is reported only for finite, positive theta pairs. Oracle convergence is
recorded as unavailable because the frozen artifact does not expose optimizer status;
the report never treats absence as success. New R oracle exports also persist
`cells_step1`, while older artifacts remain readable and report `fit_cell_order_exact=null`.

On the larger fixed fixture, the stage report reproduces the existing passing gate. Raw
theta classifications are exact (2,941 finite and 150 positive-infinite pairs), all 3,091
native comparison fits are converged, and median/maximum recorded iteration counts are
39/70. The three largest raw-intercept absolute errors are `gene_03193` (`0.00494`),
`gene_03104` (`0.00443`), and `gene_03155` (`0.00305`). Complete HVG order is not exactly
identical, while complete-rank Spearman correlation is `0.999999911` and the Top
1000/2000/3000 sets remain exact. **measured on 2026-11-02**

## Final-parameter residual isolation

The residual stage can be tested independently of selection, fitting, and
regularization by injecting Level A's final intercept and theta into the native
residual core. This is a diagnostic benchmark only: the R runtime and exported
arrays remain external and are never package or CI dependencies.

On the larger fixture, the native residual matrix agrees with the R oracle at
double-precision scale:

| Quantity | RMSE | Max abs. |
|---|---:|---:|
| clipped Pearson residual | 2.25e-14 | 3.43e-13 |
| residual mean | 1.96e-14 | 8.17e-14 |
| residual variance | 2.06e-14 | 9.79e-14 |

residual RMSE of 0.014760 to upstream parameter estimation or regularization,

## Dispersion regularization A/B

The larger fixture was also run with the same counts, manifest, raw estimator,
bandwidth selector, smoother, and thresholds while changing only the dispersion
target and inverse transform. `native` is the alpha default;
`sct_v2` uses `log10(1 + geometric_mean / theta)` and its matching inverse.

| Quantity | `native` | `sct_v2` |
|---|---:|---:|
| regularized log10(theta) RMSE | 0.046279 | 0.032621 |
| regularized log10(theta) Spearman | 0.996418 | 1.000000 |
| regularized intercept RMSE | 0.001132 | 0.003111 |
| clipped residual RMSE | 0.014760 | 0.015872 |
| clipped residual Pearson | 0.999975 | 0.999980 |
| residual variance RMSE | 0.028817 | 0.029812 |
| Top-1000 HVG Jaccard | 0.956947 | 0.951220 |
| Top-2000 HVG Jaccard | 0.986097 | 0.987084 |

The v2 transform materially improves regularized-theta agreement, but it does
not improve every downstream metric in isolation. The current outlier mask is
the union of intercept and dispersion residual outliers, so changing the
dispersion target also changes the genes used to smooth the intercept. This is
evidence to isolate outlier behavior next, not evidence to change the default.
Both modes pass the original alpha gate.

## Parameter-outlier checkpoint

The Level A exporter persists the named `model_pars_outliers` vector exposed by
the public `vst()` result. The correctness report compares this mask by gene
name, so outlier behavior is observable without reading or packaging GPL
implementation code. This checkpoint is diagnostic and has no acceptance gate
yet.

On the larger fixture, Level A marks 150 genes as parameter outliers. The
default `native` rule marks 176 genes, overlaps on 144, and has Jaccard
`0.791209`. With `dispersion_regularization="sct_v2"`, the current global-MAD
rule marks no genes, giving Jaccard `0.0` with Level A.

This localizes the mixed A/B result above: the v2 dispersion transform improves
regularized theta, but the native outlier rule is not invariant to that change
of coordinates. The 2022 paper specifies the v2 model changes but does not
fully specify the historical binned outlier helper. A clean-room compatibility
implementation therefore remains `unknown`; the next safe step is additional
black-box experiments or an independently published algorithmic specification,
not source translation.

## Raw-theta finite/Inf checkpoint

Raw-theta comparisons now report the named finite/Inf mask separately instead
of silently restricting every conclusion to pairs that are finite on both
sides. On the larger fixture, Levels A and B both contain the same 150 infinite
raw-theta genes. The native estimator contains none, so its mask Jaccard with
either oracle is `0.0` even though the finite-pair theta rank gate passes.

As a diagnostic hypothesis, the benchmark computes the method-of-moments
estimate

```text
theta_mm = mean**2 / (variance - mean)
```

when `variance > mean`, and flags a native fit when
`theta_mm / theta_native < 1e-3`. This selects 155 genes, 149 of which are in
the 150-gene Level A Inf set (Jaccard `0.955128`). The high overlap confirms
that a moment-to-fit ratio explains most of the branch difference. This broad
diagnostic includes every available raw fit.

The same rule is available as a non-default core policy for controlled A/B runs. It
exposes a separate `theta_postprocessed` mask and excludes flagged genes from smoother
training without reclassifying them as Poisson genes. Raw fits that were already infinite
are excluded separately.

## Regularization support A/B

The kernel prediction policy is exposed as `extrapolate` or `clamp`, with
`extrapolate` preserving the alpha default. On the larger fixed-manifest
fixture, clamping changes no reported value under either the `native` or
`sct_v2` dispersion transform: all prediction coordinates already lie inside
the retained training support. This zero effect is recorded rather than
generalized; datasets with abundance values outside the post-outlier training
range can exercise the explicit boundary policy.

## R-stats regularization checkpoint

The optional `regularization_method="r_stats"` path was first checked at the primitive
level against a separately installed R 4.5.2 process. The `bw.SJ` values agree to displayed
float64 precision for an eight-point exact-pair case and a 600-point binned case; four
`ksmooth` predictions and a two-grid outlier mask also match their fixed golden outputs.

The end-to-end comparison combines this method with `sct_v2`, `clamp`, and the existing
experimental `moment_ratio` theta policy. Relative to the previous
`sct_v2 + moment_ratio` result on the larger fixture:

| Quantity | native regularizer | `r_stats` regularizer |
|---|---:|---:|
| regularized intercept RMSE | 0.001067 | 0.000656 |
| regularized log10(theta) RMSE | 0.008003 | 0.008083 |
| clipped residual RMSE | 0.003331 | 0.002620 |
| residual variance RMSE | 0.004912 | 0.004577 |
| Top-1000 / 2000 / 3000 HVG Jaccard | 0.992032 / 0.997004 / 1.0 | 0.992032 / 0.997004 / 1.0 |
| parameter-outlier Jaccard | 0.910828 | 0.916667 |

The theta metric is slightly worse, while the intercept and downstream residual metrics
improve. On the small fixture, residual RMSE decreases from `0.005671` to `0.002989` and
residual-variance RMSE from `0.006621` to `0.004798`; regularized log10(theta) RMSE changes
from `0.006869` to `0.007127`.

An oracle-raw-parameter reinjection isolates regularization from the native optimizer. On
the larger fixture, the Python path reproduces the oracle's regularized intercept with
RMSE `1.50e-14` and maximum error `8.17e-14`; regularized log10(theta) has RMSE `9.00e-16`

upstream in raw fitting and theta branch selection, not in the new regularizer.

## Cox--Reid v2 fit checkpoint

explicit stages: preliminary offset-intercept fitting, per-gene Cox--Reid adjusted raw
dispersion, and an abundance-local weighted-median dispersion trend used only for the
intercept refit. External golden tests cover raw theta, zero dispersion, the trend, and
final intercepts. The complete v2 comparison combines this fit with `sct_v2`, `r_stats`,
`clamp`, and `moment_ratio`; none of these settings changes the alpha defaults. The table
below is the historical all-gene-trend checkpoint that motivated the controlled A/B.

### Offset-fit trace and gene-bin A/B

The earlier ordering/stopping explanation was tested rather than assumed. An opt-in trace
now records the moment initialization, every offset and Cox--Reid score evaluation, solver
iteration counts, stopping flags, and final parameters without changing the untraced fit.
The diagnostic also repeats the local-dispersion trend and final intercept refit under
controlled gene-bin sizes:

```bash
python -m benchmarks.diagnose_offset_fit \
  --fixture benchmark-results/large/fixture.npz \
  --manifest benchmark-results/large/fixture.selection.json \
  --r-oracle benchmark-results/large/r-oracle \
  --bin-sizes 499 500 501 1000 all \
  --top 3 \
  --output benchmark-results/large/offset-fit-diagnostics.json
```

| Local-trend gene bin | Raw-intercept RMSE vs Level A | Maximum absolute error |
|---:|---:|---:|
| 499 | 7.95e-5 | 1.94e-3 |
| **500** | **3.88e-10** | **5.44e-9** |
| 501 | 1.00e-4 | 4.39e-3 |
| 1000 | 3.05e-4 | 2.21e-3 |
| all 3091 genes | 4.24e-4 | 4.94e-3 |

The A/B holds every per-gene preliminary and dispersion fit fixed and changes only the
trend bin. The R default of 500 removes essentially the entire Level-A raw-intercept gap.
This falsifies the strong stopping-tolerance hypothesis for this fixture and identifies
gene-bin-local trend estimation as the confirmed cause. The remaining `3.88e-10` is
compatible with solver and reduction-order differences; it is not used to justify
bit-identity work. **measured on 2026-11-02**
