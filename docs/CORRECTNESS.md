# Differential correctness gate

Status: measured on 2026-11-02. Thresholds were fixed in
[SCT_V2_SPEC.md](SCT_V2_SPEC.md) before these oracle results were inspected.

## Isolation and provenance

The fixtures are synthetic Gamma--Poisson count matrices generated by
`benchmarks/generate_fixture.py` under this repository's BSD-3-Clause license. The seed is
`20261102`; inputs, ordered names, and one persisted all-eligible selection manifest define
all three levels. Level A consumes all candidates through `n_genes=NULL`/`n_cells=NULL`.
Level B's public manifest type accepts only genes that actually enter NB fitting, so the
exporter explicitly removes genes selected by the documented Poisson rule from that same
candidate list. The original manifest hash and this adapter are recorded in provenance;
Level C consumes the persisted manifest directly.

| Fixture | Shape (genes x cells) | Eligible genes | Counts SHA-256 |
|---|---:|---:|---|
| small | 800 x 240 | 778 | `daa4251f89ad449d0508ebef01bca762ea3960830b0160623d809db1131c2337` |
| larger | 3200 x 240 | 3113 | `8ae3c89d6e6fcb7290c3b750dd0544d6b2be52734fb6872a444d89ac17f9710a` |

- Level A: external R 4.5.2 process, `sctransform` 0.4.3, `glmGamPoi` 1.22.0,
  `matrixStats` 1.5.0.
- Level B: installed `Bowen-Man/sctransform-cpu` v0.4.0 at commit
  `b79041796e3f7ca3b33029adde5d7132eedd2430`, called only through its public API.
- Level C: this repository's independent NumPy/SciPy implementation.

No oracle package, R runtime, generated binary, or golden output is packaged or committed.
The exporters write only to the ignored `benchmark-results/` directory. Level A and B are
execution-time black boxes and are not dependencies of the package, build, or CI.

## Pre-registered gate result

The larger fixture exercises Top 1000/2000/3000. The table compares Level C with Level A;
all gates also passed against Level B. Pearson and Spearman are undefined for the constant
fixed-slope vector and are therefore reported as `null`, rather than assigned an artificial
correlation.

| Quantity | MAE | RMSE | Max abs. | Pearson | Spearman | Gate |
|---|---:|---:|---:|---:|---:|---|
| raw intercept | 0.001297 | 0.002313 | 0.015697 | 0.999997 | 0.999996 | pass |
| regularized intercept | 0.000880 | 0.001132 | 0.005493 | 1.000000 | 1.000000 | pass |
| fixed slope | 3.03e-15 | 3.92e-15 | 1.51e-14 | null | null | pass |
| log10 raw theta | 0.019920 | 0.167213 | 5.285959 | 0.931331 | 0.999510 | pass |
| log10 regularized theta | 0.040639 | 0.046279 | 0.146083 | 0.996828 | 0.996418 | pass |
| clipped Pearson residual | 0.010150 | 0.014760 | 0.240987 | 0.999975 | 0.999984 | pass |
| residual mean | 0.001695 | 0.002931 | 0.035053 | 0.999663 | 0.999862 | pass |
| residual variance | 0.025871 | 0.028817 | 0.094225 | 0.998885 | 0.998635 | pass |

Poisson-gene Jaccard is 1.0. HVG results are:

| Top K | Intersection | Jaccard | Required | Result |
|---:|---:|---:|---:|---|
| 1000 | 978 | 0.956947 | >= 0.90 | pass |
| 2000 | 1986 | 0.986097 | >= 0.90 | pass |
| 3000 | 2998 | 0.998668 | >= 0.90 | pass |

Level A and Level B have HVG Jaccard 1.0 at all three cutoffs and agree to numerical
precision on the other reported quantities. The small fixture also passes every applicable
gate; it has fewer than 1000 eligible genes, so no HVG cutoff is asserted there.

The large maximum raw-theta difference is one optimizer-boundary case. It is retained in
the report rather than discarded; the pre-registered theta gate uses MAE and rank
correlation, both of which pass. This is an algorithmic/statistical equivalence claim on
two fixed fixtures, not bit identity or a universal accuracy claim.

## Reproduction

```bash
python -m benchmarks.generate_fixture --output benchmark-results/large/fixture.npz --genes 3200 --cells 240 --seed 20261102
Rscript benchmarks/export_r_oracle.R benchmark-results/large/fixture benchmark-results/large/r-oracle
python -m benchmarks.export_reference --fixture benchmark-results/large/fixture.npz --manifest benchmark-results/large/fixture.selection.json --output benchmark-results/large/reference-v0.4.0.npz
python -m benchmarks.compare_correctness --fixture benchmark-results/large/fixture.npz --manifest benchmark-results/large/fixture.selection.json --r-oracle benchmark-results/large/r-oracle --reference benchmark-results/large/reference-v0.4.0.npz --output benchmark-results/large/correctness.json --enforce
```

The R and Level-B commands intentionally require separately installed external oracles.
